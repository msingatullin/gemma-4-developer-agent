## 3. Что в действительности доказано, а что опровергнуто

### Что доказано достоверно:
1. **Навигационная слепота v15:** Исходный промпт v15 содержит инструкцию `git grep -n "TOKEN" -- *.py`. В командном интерпретаторе bash шаблон `*.py` раскрывается только на файлы в корне `/workspace` (например `setup.py`), делая агента абсолютно слепым ко всем файлам в поддиректориях (`src/flask/`, `requests/`, `src/_pytest/`, `sympy/printing/`).
2. **Эмпирическая точность AST/BM25 локализации:** Локатор без привлечения LLM находит целевые файлы в 100% случаев на пилотной подвыборке из 6 задач (Recall@3 = 100%, 6/6), а на полной выборке из 42 задач достигает фактического Recall@3 = 59.52% (25/42) и Recall@1 = 47.62% (20/42), Recall@5 = 64.29% (27/42), MRR = 0.5459 (ранее ошибочно упоминавшаяся цифра 81% опровергнута и отозвана; см. точный файл `LOCATOR_BENCHMARK_RESULTS.json`).
3. **Чёткое разделение кандидатов v17:** Кандидат `v17-grep-only` использует исправленный рекурсивный `git grep` с точными настройками v15. Кандидат `v17-AST-BM25` использует AST/BM25 локатор (Recall@3 = 59.52%). Результаты одного не приписываются другому (см. `CANDIDATE_TAXONOMY.md`).
4. **Отсутствие загрязнения репозитория:** Запуск локатора через запись во временную директорию `/tmp` оставляет рабочий каталог `/workspace` на 100% чистым (`git status --short` пуст).

### Что опровергнуто и отозвано:
1. **Заявление о Solve Rate 66.7% для Gemma 4 E4B:** Отозвано. Реальная модель E4B для генерации правок не вызывалась.
2. **Экономия вызовов инструментов (15 vs 5):** Отозвано. Счётчики были зафиксированы в коде симулятора искусственно.
3. **Безусловный проход P2P-тестов:** Отозвано. Регрессионный сьют тестов не прогонялся.
4. **Готовность v17 к отправке на Kaggle:** Запрещена. В целевом окружении `Container A` скрипт `/tmp/ast_locator.py` отсутствовал без специального механизма инжекции агентом.
