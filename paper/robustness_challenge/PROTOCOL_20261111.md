# PAPER-CHAOS-20261111-001 — Frozen robustness challenge for diagnostic compaction

Date: 2026-11-11, before generating the corrupted logs or implementing the optional defensive wrapper.

## Purpose and hypothesis

Existing `paper/traceback_compressor.py` B2 and the v1 certificate are validated on **11 genuine upstream pytest logs** from 8 repositories. Hidden weaknesses may exist in terminal ANSI colors, newline modes, repeated diagnostics, interleaved stdout and native exceptions. The new experiment attempts to **falsify** (not advertise) the generalized claim that compressed outputs always preserve vital error evidence.

**Hypothesis H0:** Existing B2 and its v1 certificate correctly preserve all selected diagnostic/header/summary lines after robust ANSI-normalization for every synthetically perturbed authentic log. A counterexample would motivate a *new optional fail-open wrapper* without changing the frozen B2 implementation.

## Frozen perturbation families — eight per original log, 88 total

Use deterministic transformations (no random sampling) of each red log, with a frozen function definition committed in the test runner:

1. `ansi_critical`: ANSI SGR color wrappers around diagnostic lines, failure headers and summary lines, preserving all underlying characters.
2. `ansi_all`: ANSI SGR color on **every nonempty line**.
3. `crlf`: convert all LF to CRLF.
4. `duplicate_diagnostic`: duplicate the earliest real `E ...` or `FAILED ...` line.
5. `captured_stdout_sentinel`: inject extra captured stdout text, containing misleading non-diagnostic words and ANSI color; no actual original evidence deleted.
6. `native_traceback`: append a native two-frame Python traceback and a final synthetic `RuntimeError` sentinel (should trigger safe fallback).
7. `exception_group`: append a valid-looking `ExceptionGroup` text sentinel (should trigger safe fallback).
8. `ci_log_prefix`: prefix all lines with `[worker-0] ` to mimic structured CI log output.

All transformed logs are synthetic stress cases, not a new empirical generalization population.

## Predeclared trusted *independent* evidence oracle

- Normalize ANSI escapes (including standard CSI/SGR) and normalize CRLF/CR to LF.
- Compare **exact multiplicities of selected diagnostic E/>, exception type, FAILED/ERROR summary, and underscore failure-header lines** between the normalized raw and normalized candidate. Include expected `[worker-0]` prefixed lines only after stripping the known CI prefix; a parser that sees no recognized evidence in the *raw* log must fail closed and report `UNSUPPORTED`.
- Exact marker retention is a **bounded syntactic preservation contract**, not full semantic equivalence.
- A candidate passes only if it retains all marker multiplicities; if the compressor fails, the new optional defensive wrapper must return the input **unmodified** (fail-open) and state `FALLBACK`.
- Record whether **the legacy certificate incorrectly says PASS** when the independent oracle says diagnostic FAIL; these findings must be disclosed, not hidden.

## Decision criteria, fixed before results

- Report all **88 B2 outcomes and 88 legacy certificate verdicts** as-is.
- Build an **optional** defensive wrapper (not a modification to original B2, and not a substitute for the legacy manuscript) only if independent oracle finds loss or legacy certificate blind spots.
- Optional wrapper ACCEPT only if it preserves selected evidence on **all 88**, AND the 11 unperturbed upstream logs produce **byte-for-byte identical output** to frozen B2, with no reduction of their baseline 72.01% byte compression.
- Also require reject/detect at least 50 seeded tampered-certificate controls from existing certificate suite without allowing malformed JSON. Print the counts.
- Any failure must be published as a fail, not silently dropped; no public Kaggle writeup change or new submission without later quality validation and user approval.
